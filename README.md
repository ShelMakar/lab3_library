## Сущность `Item`

`@dataclass(frozen=True)`: объект неизменяем, поэтому результаты поиска нельзя использовать для порчи данных каталога.

| Поле | Тип | Ограничения                                                      |
|---|---|------------------------------------------------------------------|
| `item_id` | `str` | непустая строка, уникальна в каталоге (одни пробелы не считаются) |
| `name` | `str` | непустая строка (одни пробелы не считаются)                      |
| `category` | `str` | непустая строка без цифр (одни пробелы не считаются)                                        |
| `year` | `int` | от 1 до текущего года (`bool` не допускается)                    |
| `author` | `str` | непустая строка без цифр                                         |
| `language` | `str` | одно из значений `LANGUAGE`                                      |

Инварианты проверяются в `__post_init__`. Неверный объект не создаётся: выбрасывается `IncorrectItemError`, поэтому в каталог он попасть не может.

Методы `to_dict()` и `from_dict(data)` нужны для JSON.

## Каталог `Catalog`

Данные хранятся в словаре `dict[str, Item]` (ключ: `item_id`).

| Метод | Описание | Сложность |
|---|---|---|
| `add(item)` | добавляет объект; дубликат ID → `NotUniqueIDError` | O(1) |
| `get(item_id)` | возвращает объект; нет ID → `ItemNotFoundError` | O(1) |
| `remove(item_id)` | удаляет объект; нет ID → `ItemNotFoundError` | O(1) |
| `find_by_category(category)` | новый список объектов категории | O(n) |
| `find_by_name(query)` | новый список объектов, в названии которых есть подстрока `query`; регистр не важен (`casefold`) | O(n·m) |
| `len(catalog)` | число объектов | O(1) |
| `for item in catalog` | итерация по снимку каталога | O(n) |
| `item_id in catalog` | проверка наличия ID | O(1) |

Здесь n это число объектов, m длина названия.

**Порядок итерации:** порядок добавления (обеспечивается порядком вставки в `dict`). Если объект удалить и добавить снова, он окажется в конце. Итерация возвращает итератор по копии списка, поэтому изменение каталога во время цикла безопасно, а два прохода подряд дают один и тот же порядок.

**Изоляция состояния:** методы поиска всегда возвращают новый список, изменение которого не затрагивает внутреннее состояние каталога. Пустой запрос в `find_by_name` возвращает все объекты.

## Хранение (JSON)

```json
{
  "format_version": 1,
  "items": [
    {
      "item_id": "b1",
      "name": "Война и мир",
      "category": "Роман",
      "year": 1869,
      "author": "Лев Толстой",
      "language": "Russian"
    }
  ]
}
```

- `save_catalog(catalog, path)` записывает документ во временный файл `*.tmp`, затем заменяет целевой файл через `os.replace`. Если запись прервалась, старый файл остаётся целым.
- `load_catalog(path)` возвращает **новый** `Catalog`. Существующий каталог не трогается, поэтому при любой ошибке загрузки его состояние сохраняется (атомарность загрузки).

Загрузка отклоняет:

- не-JSON и файл не в UTF-8 → `BrokenFileError`;
- корень документа не объект, `items` не список → `BrokenFileError`;
- неизвестную или отсутствующую `format_version` → `IncorrectVersionFormatError`;
- невалидную запись или дубликат ID в середине файла → `BrokenFileError` с номером записи.

## Исключения

```
CatalogError(Exception)
├── IncorrectItemError            # неверная сущность
├── NotUniqueIDError              # дубликат ID
├── ItemNotFoundError             # объект не найден
├── IncorrectVersionFormatError   # неподдерживаемая версия формата
└── BrokenFileError               # повреждённый файл
```

## Пример использования

```python
from catalog import Catalog
from models import Item
from storage import save_catalog, load_catalog

catalog = Catalog()
catalog.add(Item("b1", "Война и мир", "Роман", 1869, "Лев Толстой", "Russian"))

print(len(catalog), "b1" in catalog)        # 1 True
print(catalog.find_by_name("ВОЙНА"))         # поиск без учёта регистра

save_catalog(catalog, "catalog.json")
restored = load_catalog("catalog.json")
```

## Тесты

Запуск из корня проекта:

```bash
pytest
```

С покрытием:

```bash
pytest --cov=library_catalog --cov-report=term-missing
```

Тесты покрывают:

- создание допустимой и недопустимой сущности;
- добавление, получение и удаление;
- дубликат ID и отсутствующий ID;
- поиск по категории и по имени (разный регистр);
- порядок итерации, повторная итерация;
- изоляцию результатов поиска от внутреннего состояния;
- round trip JSON (все поля сохраняются);
- повреждённый JSON, неизвестную версию формата;
- отсутствие частичных изменений каталога после ошибки загрузки.

## Принятые решения

- **Словарь вместо списка.** Поиск по ID выполняется за O(1) без линейного прохода.
- **`frozen=True`.** Объекты неизменяемы, и их нельзя испортить после помещения в каталог.
- **Загрузка во временный каталог.** Новый `Catalog` наполняется отдельно и возвращается только при полном успехе.
- **Атомарное сохранение.** Запись через `.tmp` и `os.replace`.
